## Immagine autosufficiente e correzioni

quattro moduli applicativi. Il server MCP e `/health` girano nello stesso
processo sulla porta 8765: non serve un secondo server o container.

Correzioni pubblicate:

1. Incluso `/app/smoke_test.py` nell’immagine; nessun Python necessario sul PC.
2. Esteso il test da due a sei tool locali, aggiunti token errato, notifica di
   inizializzazione, negoziazione protocollo, controllo schemi, importi/XML e
   risposte di errore. Allowlist esplicita che impedisce chiamate ai tool esterni.
3. Aggiunto HEALTHCHECK Docker basato sulla libreria standard Python.
4. Launcher standalone Windows/Linux/macOS: collaudo MCP automatico dopo avvio
   e riuso; errori del test non confusi con un avvio riuscito. Controllato anche
   l’esito della creazione volume su Windows.
5. CI: candidato senza rete prima di pubblicare; pull e test del digest effettivo
   pubblicato; verifica delle dipendenze e prova di riuso del launcher Linux.
6. Scritture esplicitamente disabilitate nel file di esempio. Aggiornate guida e
   istruzioni per esecutori autorizzati, rispettando le autorizzazioni già date.

Il pacchetto `chatgpt-plugin/` del repository è un pacchetto distinto chiamato
`fattura24-ai-open-source` versione `0.1.0`, anch’esso diretto al MCP ufficiale.
Il commit sul repository non aggiorna automaticamente il plugin installato.
La presente attività non ha sostituito il plugin installato o modificato il suo
OAuth, pubblico o permessi.

La skill `.claude/skills/fattura24/SKILL.md` descrive download ed esecuzione del
launcher senza clone, token locale privato e dati demo. Il launcher esegue e
collauda il server; il client MCP deve essere collegato separatamente con URL
`http://127.0.0.1:8765/mcp` e header `Authorization: Bearer <token locale>`.
Il token non va riportato in chat. Nessuna sessione Claude Code effettiva è stata
avviata: la verifica della skill riguarda istruzioni e script, non l’interfaccia
Claude o l’attivazione degli strumenti nella sua sessione.

## Procedura ripetibile senza clone sul PC

Un esecutore locale già autorizzato (Claude Code o collegamento locale per
ChatGPT) scarica e ispeziona il launcher della piattaforma dal repository,
quindi esegue il file salvato:

- Windows: `powershell -File <percorso-locale>/launch-standalone.ps1`
- macOS/Linux: `bash <percorso-locale>/launch-standalone.sh`

Il launcher effettua pull, avvio, generazione del token privato, esposizione
soltanto su loopback e collaudo. Docker resta l’unico runtime da installare sul
computer. Il launcher Linux/macOS richiede i normali strumenti `curl` e `openssl`.
Per container esistenti il token e il volume non vengono sostituiti; aggiornamenti
con `-ReplaceExisting` / `--replace-existing` restano operazioni esplicite.

Ripetere solo il collaudo:

```sh
docker exec fattura24-mcp python /app/smoke_test.py
```

Questa procedura non installa un esecutore locale ChatGPT, non apre un tunnel e
non configura automaticamente il client. `localhost` del cloud ChatGPT non è il
PC dell’utente.
